配置方式 ​

V4 ​

toml
# API设置
[api]
# 网易云音乐
netease-link = "https://ncm.zhenxin.me"

V2 ​

json
/// API设置
  "api": {
    /// 网易云音乐API地址
    "netease": "https://ncm.zhenxin.me"
  },
